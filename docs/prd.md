# 产品说明

聚焦 CFOP 的三阶魔方训练器。当前交付是 Web 版；长期会覆盖 iOS App、微信小程序，并对接蓝牙魔方。开源仓库配合教程内容做引流。

## 长期方向

- Web 版：当前主阵地，先打磨成可用产品，再扩硬件和平台。
- 蓝牙魔方：优先魔域，打磨稳定后再接 Gan 等品牌。
- iOS App：美区收费；中国区免费 + 广告。
- 微信小程序：免费 + 广告。
- 传播：开源 + 教程引流；社交、对战、账号体系等智能魔方配套能力默认不做，有真实用户后再考虑后端用户系统。

后置能力（当前不做）：2 / 4 / 5 阶玩法本体、教程视频、社区。阶数选择入口可先预留。

## 功能结构

顶层长期分为 5 个入口：

1. **计时**：打乱计时（默认首页）。蓝牙模式支持分段统计（Cross / F2L / OLL / PLL）。
2. **练习**：公式练习（F2L / OLL / PLL），支持分组；蓝牙模式支持打乱到练习状态。
3. **成绩**：计时成绩 + 练习成绩，列表 + 图表展示。
4. **游戏**：后置。定位为教学演示（观察模拟还原），不作为独立玩法优先开发。
5. **设置**：个人信息、蓝牙、阶数、数据导出、开源信息。

## 界面原则

采用**一套响应式布局**，同时适配手机、Pad 和桌面：

- **窄屏优先**设计，宽屏时自动扩展。
- **不单独维护**多套界面或平行代码路径。
- 布局与交互改动默认覆盖窄屏主流程；宽屏只是同一结构的延展。

## 设计约束

UI/UE 调整前先定约束，后续功能按同一规则加。

### 配色

- 主色：柔和蓝（计时器背景同色系）。
- 背景：主色浅色或深色，计时中与首页一致。
- 文字：高对比度，已完成步骤可区分。
- 高亮：当前步骤、按钮主操作。
- 危险：断开、丢弃。
- 禁用：不可操作状态。

### 图标

- 风格：线性或轻填充，统一尺寸。
- 与文字搭配：主操作可图标化，次操作保留文字。

### 交互

- 按钮层级：主操作（连接、打乱、开始）、次操作（对齐、播放控制）、危险操作（断开、丢弃）。
- 反馈：点击有状态变化，加载有提示，成功/失败有明确文案。
- 动画：转动动画时长可配置，过快可跳过。

### 字体与间距

- 计时器：大号数字，易读。
- 公式：等宽或清晰字体，已完成步骤对比度足够。
- 间距：模块间距、内边距有基准值，不随意压缩。

## 朝向

打乱和还原使用两套朝向，蓝牙和非蓝牙相同。

- 打乱：白上、黄下、绿前、蓝后、橙左、红右。打乱计时首屏的 **3D 魔方按此朝向展示**（默认白上绿前还原态；与常见计时器一致，便于对照打乱公式）。
- 还原：黄上、白下、绿前、蓝后、红左、橙右。复原状态与公式练习用这套朝向（练习立体魔方可先 z2 再观看）。

### 转向适配（已放弃）

按键重映射（绿前按 R 转橙面）实用性不强，已放弃。朝向跟随保留。

## 打乱与计时

用户可按公式打乱后再计时；非蓝牙支持短按播打乱、短按开表、长按倒计时。布局与交互细则见 `docs/design.md`。

### 响应式首屏（窄屏优先）

首屏结构（自上而下，**非计时中**）：

1. **顶部栏**：左「练习」入口；已连接时中「对齐朝向」图标；右蓝牙图标（已连接为绿色；再点确认后断开）。首页不显示设备名；不支持 Web Bluetooth 时点击 Toast「当前浏览器不支持蓝牙」。
2. **3D 魔方**：主视觉；默认白上绿前还原态；无平面图。
3. **上次成绩**（有则显示）：魔方下方大号时间（蓝牙 / 非蓝牙停表后更新）。
4. **打乱公式**：公式条 + 重新打乱。
5. **本机统计摘要**：次数 / 最好 / Ao5 / Ao12 / Ao100 / AVG。

**进行中的计时器**仅进入计时画面后出现；首页大号时间为「上次成绩」。

交互状态——**非蓝牙模式**：

1. **逐步打乱**：公式下方播放控制条（参考练习页）；魔方从白上绿前还原态起跟播。亦可在打乱**未完成**时，点击空白或按空格**自动播放**打乱。
2. **短按开表**：打乱**已完成**后，点击空白或按空格（短按）**直接进入计时**（不经过倒计时）。
3. **长按倒计时**：打乱**已完成**后，长按空白或长按空格进入倒计时画面（只显示 `0.00`，**浅绿色**闪烁）；**松手**开始计时。点击播放条、重新打乱等控件不触发。
4. **停止**：计时中再按空格或点击屏幕停表，弹出确认，可选「保留」或「丢弃」。
5. **放弃**：准备态 / 计时中右下角图标按钮可退出本次计时（不记成绩、回首页并刷新打乱）。
6. **下一轮**：停表回到首页时，3D 魔方复位为**白上绿前复原态**；关闭确认后**只更新打乱公式**（不把新打乱目标写回魔方，由播放条再逐步打乱）。

### 蓝牙模式打乱计时

已连接蓝牙魔方时，打乱计时走下列闭环；**未连接时仍用上一节非蓝牙流程**，二者不混用。

流程：

1. **连接后**：屏幕显示还原态，并跟随实体魔方。
2. **引导打乱**：显示打乱公式；逐步高亮已完成步骤；转错时显示修正提示；3D **空心描边框 + 四边同步短白箭头**提示旋转方向。
3. **观察**：打乱完成后进入观察阶段（可跳过）。观察中若实体转动，立刻结束倒计时并开表；**倒计时归零则直接进入计时画面并开表**。
4. **计时**：跳过观察后待转，实体第一次转动启动计时；观察中拧动或倒计时结束同上直接开表。计时中保留 3D 跟随，计时器为主视觉。
5. **停止**：检测到魔方回到**白上绿前复原**后自动停止（以连接后实体状态为准）；进入**成绩复盘**全屏页（替代统计弹层）；计时中点击屏幕不停表。
6. **放弃**：计时中右下角图标按钮可退出（不记成绩、回首页并刷新打乱；3D 仍跟实体），避免无法还原时卡在计时画面。
7. **下一轮**：进入复盘页即保存成绩；用户返回（或滑动返回）只退出查看并**只刷新打乱公式**，回到引导打乱；**不修改**当前 3D 魔方状态（继续跟实体）。也可「再练一次」用相同打乱重开（见成绩复盘）。

### 蓝牙还原统计

蓝牙模式停表后写入本机的统计口径（基础版已有；展示形态由成绩复盘承接）：

- **总览**：总时间、步数、TPS、转体次数、停顿率。
- **分段**：Cross、F2L×4、OLL、PLL 各自的时间、时间占比、步数、转体次数、TPS、停顿率。
- **切分**：基础版按魔方状态识别（底层十字 → F2L 对槽 → 顶面同色 OLL → 复原 PLL）；兼容手持转体（24 朝向）；不做步数均分，后续可优化。

非蓝牙模式只记总时间。首页摘要见上；列表与图表在成绩页展示，不在首页堆叠。

### 成绩复盘

还原后进入**全屏复盘页**（替代现有成绩统计弹层）。核心目标是让用户复盘过程，而非只看数字。

#### 数据记录

- 从开表起记录所有转动（含 `x` / `y` / `z` 转体），带时间戳。
- 魔域等仅上报面转的蓝牙魔方：用手持陀螺仪姿态吸附到 24 朝向，推断整步转体并写入序列（需短暂稳定，避免抖动）。
- **观察准备转体**：打乱为白上绿前；还原前常先 `z2`（黄上白下）再 `y` 选十字。这些发生在开表前，开表时按「当前手持朝向相对白上绿前」补记到轨迹开头，否则公式无法从打乱态复现还原过程。
- 转体时更新朝向；蓝牙面转按**色心绝对坐标**记账（供状态切分），复盘展示时再按累积转体映成**握持公式**（例如观察 `z2` 后绝对 `L` 显示为 `R`），并合并连续四分之一转为 `R2`。
- **步数口径 HTM**：`R2` / `U2` 计 1 步（与公式展示一致），不是四分之一转计 2。
- **转体口径**：公式中每个 `z2` / `y` / `y'` 等计 1 次；仅消去真正相邻的空转（如 `y y'`）。被面转隔开的转体分别计数。
- 计时中陀螺仪转体需稳定才写入；连拧中面转后短暂静默；**停顿后再拧**则先按当前手持朝向补记 `y` 等（F2L 换槽），并消去公式里的 `y y'` / `z z'` 空转。
- **黄上之后只认 y 环**：观察 `z2`（黄上）后，计时中转体只在 `z2` / `z2 y` / `z2 y2` / `z2 y'` 间切换，避免手抖被记成 `z`/`x` 并带歪后续握持公式。
- 按魔方状态切分阶段，输出每段公式。
- 保存本次打乱公式。

#### 复盘页内容

1. **总览**：总时间、步数、TPS、转体次数、停顿率。
2. **分段列表**：Cross / F2L1–4 / OLL / PLL；每段显示公式、步数、时间、占比。
3. **回放区**：3D 魔方可播放打乱 + 还原；支持单步前进 / 后退。
4. **打乱公式**：显示本次打乱。
5. **再练一次**：用相同打乱重新开始。

#### 交互

- 进入复盘页即自动保存成绩。
- 左上角返回（或手机浏览器滑动返回）：只退出查看并回首页，不重复保存。
- 点「再练一次」：用相同打乱重新开始（默认不保存当前成绩，或按用户选择）。
- 回放可暂停、单步。

#### 分步实现

1. 记录转动序列（含转体与朝向）。
2. 成绩页改为全屏，显示分段公式。
3. 回放。
4. 再练一次。
5. 更优解（后置，需求解器）。

## 公式练习

用户从打乱计时切到公式练习。

### 当前布局

1. 首页「练习」入口用图标，直接进入 CFOP 练习。
2. 练习界面自上而下：顶部公式选择弹层 → 3D 魔方 → 公式步骤与控制条。
3. 非蓝牙练习以观察魔方与逐步公式为主。

### 蓝牙练习闭环（待做）

1. 选择公式后，一键打乱实体魔方到练习状态。
2. 还原后记录时间。
3. 统计每个公式的练习次数、最快、平均。

### 练习逻辑

点击一条公式后，从复原状态出发，应用逆公式生成练习状态。支持多算法切换、步骤动画、步骤高亮。

公式目录写法见 `docs/formula-notation.md`。CFOP 练习收录 Wiki 标准 OLL 57 / PLL 21 / F2L 41；F2L 空槽变体单独标记（`empty-slot`），不计入标准 41。

## 成绩记录

每次打乱计时结束后，在本机记下成绩。

- **非蓝牙**：停止后不检查是否还原（用户手动停表）；弹出保留/丢弃确认，确认保留后记总时间。
- **蓝牙**：以检测到还原作为自动停表条件；进入成绩复盘全屏页即记成绩（含总览、分段与转动序列等，见上节）。

### 成绩展示（待做）

- **列表**：时间、日期、分段摘要。
- **图表**：总时间趋势、分段占比、TPS 趋势（相对成绩复盘后置）。
