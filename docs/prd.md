# 产品说明

聚焦 CFOP 的三阶魔方训练器。当前交付是 Web 版；长期会覆盖 iOS App、微信小程序，并对接蓝牙魔方。开源仓库配合教程内容做引流。

主路径仍是打乱计时，公式练习是辅助。两件事分成两个界面，用菜单或按钮切换，不堆在同一屏。

## 长期方向

- Web 版：当前主阵地，继续打磨练习与计时闭环。
- iOS App：美区收费；中国区免费 + 广告。
- 微信小程序：免费 + 广告。
- 蓝牙魔方：优先对接常见品牌（如 Gan、魔域），并评估与厂商合作；实现上优先手机端，Mac 暂不优先。
- 传播：开源 + 教程引流；社交、对战、账号体系等智能魔方配套能力默认不做，有真实用户后再考虑后端用户系统。

后置能力（当前不做）：2 / 4 / 5 阶、教程视频、社区。

## 近期优先级

按顺序推进，每次只做一件事：

1. **窄屏适配**（练习模式 + 打乱计时），为小程序 / App 做布局准备。
2. **练习统计**（次数、最好、最差、平均、Ao5 等），完善训练闭环。
3. **转向适配**（朝向感知按键重映射）：例如绿前时按 `R` 转橙面，橙前时按 `R` 转蓝面。主流 App 较少支持，作为差异化能力；复杂度高，需单独验证，不与其他功能混做。
4. **蓝牙魔方对接**（优先手机端）。
5. **模拟 CFOP 打乱与还原**（统计步数）。
6. **后端用户系统**（有真实用户后再做）。

## 朝向

打乱和还原使用两套朝向，蓝牙和非蓝牙相同。

- 打乱：白上、黄下、绿前、蓝后、橙左、红右。平面图用这套朝向。
- 还原：黄上、白下、绿前、蓝后、红左、橙右。复原状态用这套朝向。立体魔方打乱时先 z2，再执行打乱公式，再 z2，仍以黄上观看。

### 转向适配（差异化，待单独做）

当前画面按固定「绿前」理解层转按键。转向适配要在用户把整颗魔方转到其他前面色时，仍让 `R` / `U` 等按键对准「当前右手面 / 顶面」等相对方位，而不是屏幕上那一侧的绝对色。

示例：绿前时按 `R` 转橙面；转到橙前后，按 `R` 应转蓝面。

该能力与窄屏、统计解耦，做成独立功能；实现前先验证交互与测试策略。

## 打乱与计时

打乱完成后，用户可以先观察，再开始计时。

打乱生成失败或魔方状态异常时，允许重新打乱，不中断计时流程。

### 非蓝牙

1. 给出打乱公式。
2. 给出打乱完成后的立体魔方，以及一张打乱后的平面图。
3. 按住空格进入准备，松开后开始计时，再次按下空格停止。
4. 停止时不检查魔方是否还原。时间、打乱公式和日期记为本次成绩。

### 蓝牙

1. 给出打乱公式。画面上的魔方保持复原，使用打乱朝向。
2. 用箭头提示下一步。用户转动时，画面跟着转，并更新打乱进度。
3. 转错时提示用户。
4. 半圈要能识别两个方向。`R2` 和 `R'2` 都算同一步完成。
5. 打乱完成后可以观察。用户第一次转动开始计时。
6. 魔方回到复原后停止计时。时间、打乱公式和日期记为本次成绩。

## 公式练习

用户从打乱计时切到公式练习，选择要练的步骤，例如 F2L、OLL。

点击一条公式后，从复原状态出发，应用该公式的逆公式，生成需要用该公式解决的状态，再开始练习。画面显示公式和这个练习状态，并提供计时。

每个公式需要对应的图案示意，方便按图案选择。

从练习状态到目标状态，可以单步执行，也可以用一个按钮按步播放动画，直到目标状态。

公式练习在本机记录每个公式的练习次数、最好时间、最差时间、平均时间、Ao5（统计项按近期优先级推进）。

蓝牙魔方从复原状态开始，按步骤提示，魔方跟着用户转，直到这次练习还原。

F2L 除基础情况外，还要覆盖玩家面对的四个槽位：前左、前右、后左、后右。空槽练习是：还有未还原的 F2L 时，练习利用空槽来加快还原。练习时在 3D 魔方上高亮当前空槽位置（当前未做）。

## 成绩记录

每次打乱计时结束，都在本机记下一条成绩。最小字段为：时间、打乱公式、日期、模式（非蓝牙 / 蓝牙）、是否分段（预留）。后端与用户系统优先级低，有真实用户后再做。

非蓝牙按下空格停止后，不检查魔方是否还原。

分段计时，例如十字、F2L、OLL，以后再考虑，当前不做。

## 界面切换

两个界面：

- 打乱计时
- 公式练习

用菜单或按钮切换。布局需同时支持桌面与窄屏（手机 / 小程序视口）。
