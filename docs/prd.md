# 产品说明

三阶魔方的主功能是打乱和计时，并记下成绩。公式练习是辅助功能，排在打乱计时之后。两件事分成两个界面，用菜单或按钮切换，不堆在同一屏。

智能魔方配套应用里的社交、对战、课程、账号和复杂统计不纳入。公式练习仍按每个公式记录次数和时间，见下文。

## 当前优先级

非蓝牙打乱计时闭环已基本完成。

公式练习按这个顺序做：

1. 从复原状态应用公式的逆公式，生成练习状态。
2. 为每个公式配图案示意。
3. 记录每个公式的练习次数、最好时间、最差时间、平均时间、Ao5。

蓝牙跟转、成绩后端、朝向设置和分段计时都已明确，但不在当前这一步。

## 朝向

打乱和还原使用两套朝向，蓝牙和非蓝牙相同。自行切换朝向的设置以后再做，当前不做。

- 打乱：白上、黄下、绿前、蓝后、橙左、红右。平面图用这套朝向。
- 还原：黄上、白下、绿前、蓝后、红左、橙右。复原状态用这套朝向。立体魔方打乱时先 z2，再执行打乱公式，再 z2，仍以黄上观看。

## 打乱与计时

打乱完成后，用户可以先观察，再开始计时。

打乱生成失败或魔方状态异常时，允许重新打乱，不中断计时流程。

### 非蓝牙

1. 给出打乱公式。
2. 给出打乱完成后的立体魔方，以及一张打乱后的平面图。
3. 按住空格进入准备，松开后开始计时，再次按下空格停止。
4. 停止时不检查魔方是否还原。时间、打乱公式和日期记为本次成绩。

### 蓝牙

1. 给出打乱公式。画面上的魔方保持复原，使用打乱朝向。
2. 用箭头提示下一步。用户转动时，画面跟着转，并更新打乱进度。
3. 转错时提示用户。
4. 半圈要能识别两个方向。`R2` 和 `R'2` 都算同一步完成。
5. 打乱完成后可以观察。用户第一次转动开始计时。
6. 魔方回到复原后停止计时。时间、打乱公式和日期记为本次成绩。

## 公式练习

用户从打乱计时切到公式练习，选择要练的步骤，例如 F2L、OLL。

点击一条公式后，从复原状态出发，应用该公式的逆公式，生成需要用该公式解决的状态，再开始练习。画面显示公式和这个练习状态，并提供计时。

每个公式需要对应的图案示意，例如 OLL 的小鱼显示小鱼图案，方便按图案选择。

从练习状态到目标状态，可以单步执行，也可以用一个按钮按步播放动画，直到目标状态。

公式练习在本机记录每个公式的练习次数、最好时间、最差时间、平均时间、Ao5。

蓝牙魔方从复原状态开始，按步骤提示，魔方跟着用户转，直到这次练习还原。

F2L 除基础的 41 种情况外，还要覆盖玩家面对的四个槽位：前左、前右、后左、后右。空槽练习是：还有未还原的 F2L 时，练习利用空槽来加快还原。练习时在 3D 魔方上高亮当前空槽位置。

## 成绩记录

每次打乱计时结束，都在本机记下一条成绩。最小字段为：时间、打乱公式、日期、模式（非蓝牙 / 蓝牙）、是否分段（预留）。后端优先级低，当前不做。

非蓝牙按下空格停止后，不检查魔方是否还原。

分段计时，例如十字、F2L、OLL，以后再考虑，当前不做。

## 界面切换

两个界面：

- 打乱计时
- 公式练习

用菜单或按钮切换。先做打乱计时，再做公式练习。

## 范围控制

本文档仅描述当前已确认需求。未提及的功能默认不做，避免范围蔓延。
