# 产品说明

聚焦 CFOP 的三阶魔方训练器。当前交付是 Web 版；长期会覆盖 iOS App、微信小程序，并对接蓝牙魔方。开源仓库配合教程内容做引流。

## 长期方向

- Web 版：当前主阵地，继续打磨练习与计时闭环。
- iOS App：美区收费；中国区免费 + 广告。
- 微信小程序：免费 + 广告。
- 蓝牙魔方：优先对接常见品牌（如 Gan、魔域），并评估与厂商合作；实现上优先手机端，Mac 暂不优先。
- 传播：开源 + 教程引流；社交、对战、账号体系等智能魔方配套能力默认不做，有真实用户后再考虑后端用户系统。

后置能力（当前不做）：2 / 4 / 5 阶玩法本体、教程视频、社区。阶数选择入口可先预留。

## 功能结构

顶层长期分为 5 个入口：

1. **计时**：打乱计时（默认首页）。分段计时（Cross / F2L / OLL / PLL）后置独立做。
2. **练习**：公式练习（F2L / OLL / PLL），支持分组；收藏和自定义算法后置。
3. **成绩**：计时成绩 + 练习成绩，本地统计（次数、最佳、平均、Ao5）。
4. **游戏**：后置。定位为教学演示（观察模拟还原），不作为独立玩法优先开发。
5. **设置**：个人信息、蓝牙、阶数、数据导出、开源信息。

**当前首屏范围**：顶部只保留**练习入口**。成绩、设置可后置或仅占位，不在打乱计时响应式首屏中实现。计时侧重完整还原计时，练习侧重公式识别与执行，两者不重复堆叠。

## 界面原则

采用**一套响应式布局**，同时适配手机、Pad 和桌面：

- **窄屏优先**设计，宽屏时自动扩展。
- **不单独维护**多套界面或平行代码路径。
- 布局与交互改动默认覆盖窄屏主流程；宽屏只是同一结构的延展。

## 近期优先级

按顺序推进，每次只做一件事：

1. **打乱计时响应式首屏**（窄屏优先）：只改布局与交互状态，不改打乱 / 计时核心逻辑。
2. **练习模式响应式布局**：手风琴选公式；练习界面优先魔方、公式与控制条；计时中只显示计时器。
3. **练习统计**（次数、最好、最差、平均、Ao5 等），先本地存储。
4. **转向适配**（朝向感知按键重映射）：绿前按 R 转橙面，橙前按 R 转蓝面。差异化能力；先做「手动设置前面色」的最小可用版本单独验证，不与窄屏、统计、蓝牙混做。
5. **蓝牙魔方对接**（优先手机端）。
6. **模拟 CFOP 打乱与还原**（统计步数，可作为游戏/教学演示）。
7. **后端用户系统**（有真实用户后再做）。

## 已完成

- 非蓝牙打乱计时闭环（打乱、立体魔方、平面图、空格计时、本机成绩）。
- F2L / OLL / PLL 公式练习：多算法、括号分组、步数、控制条、动画、步骤高亮。
- OLL 六类分组 + 练习列表折叠。
- OLL / PLL / F2L 缩略图（F2L 为立体示意）。
- F2L 练习简化显示：顶面（黄层）只突出相关角棱，底层白色不误灰；可开关。

## 朝向

打乱和还原使用两套朝向，蓝牙和非蓝牙相同。

- 打乱：白上、黄下、绿前、蓝后、橙左、红右。打乱计时首屏的 **3D 魔方与平面图都按此朝向展示**（与常见计时器一致，便于对照打乱公式核对）。
- 还原：黄上、白下、绿前、蓝后、红左、橙右。复原状态与公式练习用这套朝向（练习立体魔方可先 z2 再观看）。

### 转向适配（差异化，待单独做）

当前画面按固定「绿前」理解层转按键。转向适配要在用户把整颗魔方转到其他前面色时，仍让 `R` / `U` 等按键对准「当前右手面 / 顶面」等相对方位。

示例：绿前时按 `R` 转橙面；转到橙前后，按 `R` 应转蓝面。

该能力与窄屏、统计、蓝牙解耦，做成独立功能；**MVP 为用户手动设置当前前面色**，验证交互后再考虑朝向感知。

## 打乱与计时

打乱完成后，用户可以先观察，再开始计时。

### 响应式首屏（窄屏优先）

首屏结构（自上而下）：

1. **顶部栏**：仅保留**练习入口**（窄屏下可图标化）。阶数、蓝牙、成绩、设置不在本步实现（可后置或极简占位，不挤占主流程）。
2. **打乱公式**：显示在上方。
3. **3D 魔方**：中间展示打乱后的立体魔方。
4. **计时器**：魔方下方，默认 `0.000`（**只做总时间**）。
5. **平面图**：与 3D 魔方二选一切换（白上绿前，色板与立体一致）；切换按钮靠预览区一角。

交互状态（触控为主；桌面可继续用空格）：

1. **准备**：长按屏幕进入准备；计时器变红并闪烁；可加约 0.3s 延迟防误触。
2. **计时中**：松手后开始计时；屏幕**只显示计时器**，其他元素隐藏。
3. **停止**：再次点击停止计时后弹出确认：显示本次时长，可选「保留」或「丢弃」。保留则记下成绩；丢弃则不记。随后关闭弹窗、刷新打乱公式 / 3D / 平面图，回到首屏。

蓝牙连接后（对接阶段）：3D 魔方可跟随陀螺仪；同时允许用户手动调整朝向与实体魔方对齐。

### 分段计时

**响应式首屏不做分段 UI**，只做总时间计时。成绩侧可预留分段字段；Cross / F2L / OLL / PLL 分段计时后续独立实现，与练习中的「只练某步骤」配合，不在首屏混做。

## 公式练习

用户从打乱计时切到公式练习。

### 响应式布局（窄屏优先）

1. 进入后用手风琴选择：F2L / OLL / PLL → 分组 → 公式。
2. 练习界面优先显示魔方、公式和控制条；公式列表可折叠。
3. 计时中同样只显示计时器。

### 练习逻辑

点击一条公式后，从复原状态出发，应用逆公式生成练习状态。支持多算法切换、步骤动画、步骤高亮。

公式练习在本机记录次数、最好、最差、平均、Ao5。

支持收藏常用公式和自定义算法（后续步骤）。

## 成绩记录

每次计时或练习结束，在本机记下成绩。最小字段：时间、打乱/公式、日期、模式、类型（计时 / 练习）。

非蓝牙停止后不检查是否还原。

分段字段可预留；当前计时与首屏只记录总时间。

## 设置

后置入口。规划包含：个人信息、蓝牙连接、阶数选择、数据导出（成绩备份）、开源与贡献信息。不在打乱计时响应式首屏中实现。
