# 公式写法约定

配合 Issue #56：目录更新、宽边旋转去重、写法优化。解析器仍接受旧写法；**目录默认**按下列规则收录。

## 宽边旋转去重

当同一条 OLL（或同类）同时存在：

- 宽层写法：`r` / `l`（及 `r'` / `l'` / `r2` 等）
- 与之等价的中层拆写：`R`+`M` / `L`+`M` 组合（如 `R M'` ≈ `r`）

**只保留宽层写法**作为 `moves`（及 `algs[0]`）。去掉等价的 R+M / L+M twin。

仍可保留**效果不同**的备选算法（例如另一套 F 系指法），不在本规则内删除。

若某条只有 R+M、没有宽层 twin，则保留 R+M，不强行改写。

引擎仍可解析 `R M'` 与 `r`；去重只约束目录收录，避免同一效果双挂。

## 双转写法：`M2` → `M'2`

中层（及同类）180° 在目录中优先写成 `M'2`（与常跟 `M'` 的指法方向一致），不写裸 `M2`。

解析 / 动画：`M'2` 归一为 SiGN 的 `M2'`，**保留 `M'` 方向的 180° 转动**（不要收成裸 `M2`，否则立体动画会按 `M` 正向转）。`U'2` 等同类写法同样接受。界面展示仍用目录里的 `M'2`。
