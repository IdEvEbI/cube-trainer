# 魔域宽层 / 中层转动包采集（临时）

## 目的

魔域转动包只有外层 `F/B/U/D/L/R`。宽层（`r`…）与中层（`M/E/S`）需靠「外层序列 + 陀螺仪相对变化」推断。

临时页：**连接魔方 → 顶栏「采」→ 选记号 → 开始记录 → 拧 → 保存**。结果可复制 Markdown / JSON，并写入 `localStorage`（`cube-trainer.moyu-layer-capture.v1`）。

## 真机全量表（2026-11-11，多数票）

每记号采 4 次；`d` 系含二次重采。匹配以 **moves 多重集 + `gyroDelta`** 为准，忽略武装等待造成的首间隔与绝对 `before`/`after`。

### 宽层（对面外层；`*2` 为两下）

| label             | moves                        | Δ                              |
| ----------------- | ---------------------------- | ------------------------------ |
| r / r' / r2 / r'2 | `L` / `L'` / `L L` / `L' L'` | `x'` / `x` / `z2 y2` / `z2 y2` |
| l / l' / l2 / l'2 | `R` / `R'` / `R R` / `R' R'` | `x` / `x'` / `z2 y2` / `z2 y2` |
| f / f' / f2 / f'2 | `B` / `B'` / `B B` / `B' B'` | `z` / `z'` / `z2` / `z2`       |

| d / d' / d2 / d'2 | `U` / `U'` / `U U` / `U' U'` | `y` / `y'` / `y2` / `y2`       |

说明：

- 对面规律：`r↔L`，`l↔R`，`f↔B`，`b↔F`，`u↔D`，`d↔U`（首采曾误记 `f↔D` 等，已废弃）。
- `*2` / `*'2` **不是**与四分之一同包；真机慢拧常报两下四分之一。
- `d2`/`d'2` 的相对吸附偶发 `x y2` 或空，期望仍记 `y2`，匹配用转角软兜底。
- 宽层必须 `包 + 陀螺有整机分量`：单包 `L` 且陀螺静默是外层 `L`，不是 `r`。

## 层转后错面 / 整机假转

**贴纸写入白名单**：连接（facelets）/ 断开 / 前台对表；引导里仅「步到位」写公式前缀（`setAbsoluteAlg`，alg 未变则跳过）。过程中 facelets 只对表，3D 只靠转动包与陀螺 scrub——禁止 poll 重刷整盘。

**跟转 3D**：宽层/中层走**公式 `Twisty.alg` 旋转**（`setAbsoluteAlg`），色心跟公式语义（例：`z2…f'` 后顶心橙）。禁止用 `setAbsoluteFromPattern` 钉贴图「拧回黄上」。`absoluteAlgToNailedDisplayPattern` 仅给 facelets/对表。

**映面候选**：公式转体优先，再 live relative / 取反，再**已完成层转的公式色心 Δ 累积**（`guideLayerCenterOrientationAlg`）。单步色心 Δ 仍取反（`M'`≡`x` 时保留 `x'`）；**多步累积整串不取反**（`x' z` 取反 `z' x` 会把 `B` 收成 `R`）。  
色心 Δ 与陀螺表对照（L9）：`r/l/u/d/M/E` 族色心 ≡ **invert(陀螺)**（例：`r'` 陀螺 `x`、色心 `x'`；`M'` 陀螺 `x'`、色心 `x`）；`f/b/S` 与陀螺同向；`*2` 与陀螺一致。3D 跟 `setAbsoluteAlg` 公式色心，**禁止 poll 贴图**拧回黄上。  
勿改回「只用 Last 陀螺」：`r' b'` 会丢掉 `r'` 色心，下一步 `R` 收成 `B`（#160）。手势匹配仍用陀螺表 / Last。  
**层转后残留窗**：`beginLayerEchoQuiet` 可带 `liveQuat` 重采 home（首页公式空时有用）；游戏黄上 relative 基准是**公式姿态**，故残留未清时 **faceOrientCandidates 不叠 live relative**，只留公式 + 色心累积。否则 `S'` 的 `z'` 相对 `z2 y` 会吸附成 `x'`，`D`/`U` 误收成下一步 `L`（#159）。

**转体 z2 / y**：双步转体用短稳定窗，且实况 relative 已满足即可确认（勿只等 hold committed，否则抖动反复重置，要猛晃才过）。画面：mesh 锁单位；公式 `startGuideStepGyroTrack` + `rotationGuideVisualProgress` scrub；到位 `finishGuideStepGyroTrack` 补间，禁止 `setAbsoluteAlg` 闪切。

**层转动画**：进度 = 陀螺为主、包作下限；包收齐后视觉不满格（防双包同帧闪切），`finishGuideStepGyroTrack` 补间到终点。`startGuideStepGyroTrack(move, baseAlg)` 须带已完成前缀，整段进 Twisty.alg scrub；开轨道摘盒后须立刻 `rebindPendingMoveHint`。mesh 锁单位。

L9（**通过 2026-11-13**）：层转一步 scrub 后保持该 alg；mesh 锁单位。BLE 面转：`resolveGuideBleFaceMove`——色心已对上期望则不映（避 live `y` 噪声 L→F）；否则按引导起点→live 朝向映回（未摆正 F'→U'）。字母偶发不符时 facelets 兜底。

**共用模块**：首页打乱与游戏页跟拧映面均走 `src/modules/scramble/guideBleFaceRemap.ts`（`guideBleFaceOrientCandidates` / home 状态机）。禁止各页再写一套「期望 Δ」或「绝对 held 替换公式」。游戏页：relative 基准用**公式转体姿态**（防 Cross `z2` 双计）；候选链为 match → 相对取反 → 仅公式。**不要**把层转期望 Δ 全历史（如 `S' S d'` → `z' z y'`）塞进候选，否则失败时末个脏 Δ 会把误面收成「请转 L」。黄上 `z2` 时禁止 `resolveGuideBleFaceMove` 的 raw===expected 原样短路。

## 层转后交接（决策冻结）

L0–L9 盖住**单步**宽层/中层识别。游戏页后置还有三套规则（对偶残留、转体确认、色心映面），组合态必须写进本表与单测；禁止只靠真机整把连测或口头补丁。

改残留 / 静默吞包 / 转体确认 / 槽位映面任一行为：**先在本矩阵增行（或标红）→ 再改代码 → 单测变绿**。真机新瓢：先记一行，再修。

### 决策规则

**色心下一步**（层转刚确认后的固件外层包）：

| 条件                                       | 动作                                                        |
| ------------------------------------------ | ----------------------------------------------------------- |
| `raw ∈ echo` 且 `raw === expected`         | **放行**（如 `S'`→`F'`）                                    |
| `raw ∈ echo` 且公式朝向映面 === `expected` | **放行**（如黄上后握持 `R` 报绝对 `L`，`L`∈`r` echo；#158） |
| `raw ∈ echo` 且仅层转 Δ 才映成期望         | **丢弃**（如 `M'` 回声假命中）                              |
| `raw ∉ echo`                               | 走色心槽位 / 朝向映面；命中期望则推进                       |

`echo(token)` = 该层转指纹包及其取逆（见上文全量表 + `layerEchoFaceMoves`）。静默窗内对偶吞包与残留过滤共用「原包 === 期望则不吞」规则。

**转体下一步**（层转或宽层后公式下一步为 `x/y/z`）：

| 条件                                       | 动作                                                          |
| ------------------------------------------ | ------------------------------------------------------------- |
| 进入该步首帧、仅绝对朝向已到位             | **不可确认**（宽层 `d'`/`u` 后陀螺常已是 `y'`，会无提示跳过） |
| 相对步起点 hold 已提交且满足期望（含正反） | **可确认**                                                    |
| 进入该步已满 hold 窗，且绝对朝向仍到位     | **延迟确认**（提示已画出）                                    |
| 双步 `*2`                                  | 看绝对朝上到位（勿单靠相对 Δ）                                |

### 生成矩阵（第 1 层安全网）

L0–L9 盖住**单步**识别；交接瓢出在组合空间。E1–E17 是真机踩到才加的**回归锚点**，盖不住笛卡尔积。改映面 / 残留 / 转体前：先改本节生成规则与 `layerHandoffGenerated.test.ts`，再改代码；禁止为单只瓢加 `if`。

**覆盖维度**（先不做 `*2`）：

| 维         | 取值                                           |
| ---------- | ---------------------------------------------- |
| 刚完成层转 | `r/r'/l/l'/f/f'/b/b'/u/u'/d/d'/M/M'/E/E'/S/S'` |
| 下一步     | 外层 `U/D/L/R/F/B` 及撇；转体 `x/y/z` 及撇     |
| 朝向       | 白上（公式朝向空）；黄上（`z2`）               |
| 残留窗     | 开 / 关（关：不对偶残留丢弃；开：按下列规则）  |
| 面转输入   | 色心 ble 为上述 12 个外层记号之一              |

**生成期望（与「决策规则」同构）**：

- 残留窗**关**：面转路径不因对偶残留而丢弃（`want=accept`）。
- 残留窗**开**且 `raw ∈ echo(层转)`：
  - `raw === expected` → accept
  - 仅**公式朝向**映面后 `=== expected` → accept（勿用层转脏 Δ 放行）
  - 否则 → reject（丢弃）
- 残留窗**开**且 `raw ∉ echo` → accept（本过滤器不拦；交色心槽位 / 映面）
- 下一步为转体：进入 0ms 且无相对 hold → reject（勿首帧跳过）；本生成表不展开满 hold / relative committed（仍由 E6–E9 锚）

**与 E1–E17 的关系**：E 行保留作回归锚点（`layerHandoffMatrix.test.ts`），可增不可 silently 删。生成表不替换 E；锚点若落在生成维度内，生成期望必须与 E 的 want 一致。超出本维的锚点（如 E15/E16 的 `z2 y`、E17 多步色心累积、E13 红测）仍只靠 E 行，不强行扩维。

单测：`src/modules/scramble/layerHandoffGenerated.test.ts`。

### 离线回放（第 2 层安全网）

第 1 层盖**单步**交接规则；真机瓢常是一整段（层转 → 下一步 → 朝向变化）。把色心包 + 陀螺快照写成 fixture，在 CI 里用 `GuideFollowController` + `GuidedScramble` 重放，不必再拧魔方。

**不要**改 `layerCapture.ts`（那是单记号指纹采集）。回放入口：`src/modules/scramble/guideReplay.ts`；fixture 目录：`src/fixtures/guide-replay/`。

**fixture 格式（JSON）**：

| 字段              | 含义                                                                |
| ----------------- | ------------------------------------------------------------------- |
| `id`              | 稳定短名                                                            |
| `displayMoves`    | 引导公式步（与游戏页展示一致）                                      |
| `requireYellowUp` | 可选，默认 `true`（游戏黄上对表）                                   |
| `events[]`        | 有序事件：`{ type:"orient", t, alg }` 或 `{ type:"face", t, move }` |
| `expect`          | `{ progress, done, sawWrong }`                                      |

- `orient.alg`：白上起算姿态串；层转用文档**陀螺** Δ（如 `r'`→`x`，`b'`→`z`），手写即可，不要求新采。
- 非面转步：当 `orient.alg` 等于「完成当前步后」的期望串时自动 `confirm`（骨架；对应真机到位）。
- `face.move`：色心绝对包；经静默 / 残留 / 映面后，仅当收成期望面转才 `applyGuidedMove`。

**如何加新瓢**：

1. 在矩阵或抽检记下现象（可先补 E 行）。
2. 新增 `src/fixtures/guide-replay/<id>.json`：公式 + 最少 orient/face 事件 + `expect`。
3. 在 `guideReplay.test.ts` 读 fixture 断言；先红后绿。
4. **禁止**为单只瓢在跟拧生产路径加 `if`；先改生成矩阵 / 锚点 / 本回放，再改代码。

首条：`e17-r-prime-b-prime-R.json`（E17 / #160：`z2 r' b' R`，绝对 `B` 不收成 `R`，`D` 推进）。
