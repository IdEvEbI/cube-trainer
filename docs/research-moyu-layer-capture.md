# 魔域宽层 / 中层转动包采集（临时）

## 目的

魔域转动包只有外层 `F/B/U/D/L/R`。宽层（`r`…）与中层（`M/E/S`）需靠「外层序列 + 陀螺仪相对变化」推断。

临时页：**连接魔方 → 顶栏「采」→ 选记号 → 开始记录 → 拧 → 保存**。结果可复制 Markdown / JSON，并写入 `localStorage`（`cube-trainer.moyu-layer-capture.v1`）。

## 真机全量表（2026-11-11，多数票）

每记号采 4 次；`d` 系含二次重采。匹配以 **moves 多重集 + `gyroDelta`** 为准，忽略武装等待造成的首间隔与绝对 `before`/`after`。

### 宽层（对面外层；`*2` 为两下）

| label             | moves                        | Δ                              |
| ----------------- | ---------------------------- | ------------------------------ |
| r / r' / r2 / r'2 | `L` / `L'` / `L L` / `L' L'` | `x'` / `x` / `z2 y2` / `z2 y2` |
| l / l' / l2 / l'2 | `R` / `R'` / `R R` / `R' R'` | `x` / `x'` / `z2 y2` / `z2 y2` |
| f / f' / f2 / f'2 | `B` / `B'` / `B B` / `B' B'` | `z` / `z'` / `z2` / `z2`       |
| b / b' / b2 / b'2 | `F` / `F'` / `F F` / `F' F'` | `z'` / `z` / `z2` / `z2`       |
| u / u' / u2 / u'2 | `D` / `D'` / `D D` / `D' D'` | `y'` / `y` / `y2` / `y2`       |
| d / d' / d2 / d'2 | `U` / `U'` / `U U` / `U' U'` | `y` / `y'` / `y2` / `y2`       |

说明：

- 对面规律：`r↔L`，`l↔R`，`f↔B`，`b↔F`，`u↔D`，`d↔U`（首采曾误记 `f↔D` 等，已废弃）。
- `*2` / `*'2` **不是**与四分之一同包；真机慢拧常报两下四分之一。
- `d2`/`d'2` 的相对吸附偶发 `x y2` 或空，期望仍记 `y2`，匹配用转角软兜底。
- 宽层必须 `包 + 陀螺有整机分量`：单包 `L` 且陀螺静默是外层 `L`，不是 `r`。

### 中层（双包；`*2` 为四包 = 单步两倍）

| label    | moves（多重集）           | Δ                 |
| -------- | ------------------------- | ----------------- |
| M / M'   | `L' R` / `L R'`           | `x` / `x'`        |
| M2 / M'2 | `L' L' R R` / `L L R' R'` | `z2 y2` / `z2 y2` |
| E / E'   | `D' U` / `D U'`           | `y` / `y'`        |
| E2 / E'2 | `D' D' U U` / `D D U' U'` | `y2` / `y2`       |

顺序可对调；**撇号方向**不能对调。`M` 与 `M'` 多重集不同（首采曾误为同键，已废弃）。

## 层转后错面 / 整机假转

**贴纸写入白名单**：连接（facelets）/ 断开 / 前台对表；引导里仅「步到位」钉公式前缀（alg 未变则跳过）。过程中 facelets 只对表，3D 只靠转动包与陀螺 scrub——禁止 poll 重刷整盘。

**层转动画**：进度 = 陀螺为主、包作下限；包收齐后视觉不满格（防双包同帧闪切），`finishGuideStepGyroTrack` 补间到终点。`startGuideStepGyroTrack(move, baseAlg)` 须带已完成前缀。mesh 锁单位。
