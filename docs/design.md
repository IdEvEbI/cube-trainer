# 产品设计（轻量）

对齐 `docs/prd.md` 的设计约束与已完成能力。本文锁定 UI/UE 统一时的色值、组件层级与文案；后续改布局以本文为准。窄屏优先，一套布局适配宽屏。

色值取自当前 Web 实现中已稳定使用的主色系，统一时优先收敛到下列 token，避免再散落新色。

## 1. 配色

| Token                                 | 色值                     | 用途                                               |
| ------------------------------------- | ------------------------ | -------------------------------------------------- |
| 主色 `color.primary`                  | `#4A7EB5`                | 计时区背景、结果确认底、主操作同色系强调           |
| 主色深 `color.primary-deep`           | `#2A5078`                | 主操作按钮上的深色字（浅底按钮）                   |
| 页面底 `color.surface`                | `#4A7EB5`                | 打乱计时 / 练习主舞台（计时中与首页一致）          |
| 深色块 `color.surface-dark`           | `#1C1F27`                | 打乱条、次按钮实心底、弹层深底                     |
| 浅色块 `color.surface-light`          | `#F3F0E8`                | 顶栏「练习」等浅底控件                             |
| 文字主（浅底上）`color.text-on-light` | `#12141A`                | 浅色按钮字、高亮步骤字                             |
| 文字主（深底上）`color.text`          | `#F7FBFF`                | 正文、公式、计时数字默认                           |
| 文字次 `color.text-muted`             | `#B7B1A4`                | 顶栏次要信息                                       |
| 文字弱 `color.text-dim`               | `#8D887D`                | 提示、禁用倾向说明、空状态                         |
| 高亮 `color.highlight`                | `#FFD500`                | 当前公式步、准备态强调、复选强调、打乱引导 3D 箭头 |
| 危险 `color.danger`                   | `#FF3B30`                | 计时准备闪烁、需强警示                             |
| 危险浅字 `color.danger-soft`          | `#FFE0E0`                | 打乱转错提示                                       |
| 成功 `color.success`                  | `#D7FFE8`                | 蓝牙已连接状态                                     |
| 警告 `color.warning`                  | `#F0C9A0`                | 蓝牙过程提示（同步中、对齐等）                     |
| 边框 `color.border`                   | `rgb(247 251 255 / 42%)` | 次操作描边、卡片线                                 |
| 禁用                                  | 原色 + `opacity: 0.65`   | 连接中、不可点；光标 `wait` / `not-allowed`        |

魔方色块（3D / 练习缩略图）保持竞赛色：白 `#FFFFFF`、黄 `#F4F400`、绿 `#44EE00`、蓝 `#2266FF`、红 `#FF0000`、橙 `#FF8000`。不与 UI token 混用。

## 2. 图标

- **风格**：线性，描边约 1.5–2px，圆角端点；不使用彩色插画图标。
- **尺寸**：触控图标 `20×20`；与 `40px` 高圆角按钮居中。列表缩略图（OLL/PLL/F2L）单独尺寸，不与导航图标混用。
- **与文字**：
  - 主入口可只留图标（如首页「练习」）。
  - 主操作若空间紧可用「图标 + 短文案」；蓝牙「连接 / 断开」保留文字。
  - 次操作默认文字（「对齐朝向」「跳过观察」、打乱/练习播放控件）；窄屏可缩字，不改成纯图标除非已约定。
- **触控**：图标按钮最小点击区 `40×40`。

## 3. 交互

### 按钮层级

| 层级     | 视觉                                             | 典型操作                                       |
| -------- | ------------------------------------------------ | ---------------------------------------------- |
| 主操作   | 实心浅底 `#F7FBFF` + 深字，或深底实心 + 粗体白字 | 连接蓝牙、重新打乱、结果「保留」、练习播放主控 |
| 次操作   | 透明 / 深底 + 描边，或描边胶囊                   | 对齐朝向、跳过观察、打乱播放控制、算法切换     |
| 危险操作 | 描边浅字或与主操作对位的弱样式；文案明确         | 断开蓝牙、结果「丢弃」                         |

同一弹层内：「保留」为主，「丢弃」为次/危险弱样式，避免双主按钮。

### 反馈

- **点击**：按钮按下有背景或边框变亮；操作后 `blur`，避免挡住空格计时。
- **加载**：蓝牙连接中按钮 `disabled` + 状态文案（见第 7 节）。
- **成功 / 失败**：顶栏状态条或公式区旁注；失败用完整短句，不吞错。
- **计时准备（非蓝牙）**：进入准备后计时器出现，数字变 `color.danger` 并闪烁；松手进入计时画面。

### 动画时长

| 场景           | 时长 / 规则                                       |
| -------------- | ------------------------------------------------- |
| 非蓝牙触控预备 | 长按满 `300ms` 进入准备（键盘空格立即准备）       |
| 蓝牙跟转动画   | 单步约 `60–220ms`；协议间隔 `< 90ms` 或积压时瞬切 |
| 练习步骤播放   | 沿用播放器既有步进时长；用户可暂停 / 单步         |
| 观察倒计时     | 默认 `15s`，可跳过                                |
| 页面切换       | 不做大段过渡动画；以布局显隐为主                  |

## 4. 字体与间距

### 字号与字重

| 角色               | 字号（窄屏 → 宽屏）              | 字重           | 备注                                           |
| ------------------ | -------------------------------- | -------------- | ---------------------------------------------- |
| 计时器（仅计时中） | `clamp(4.2rem, 22vw, 7.5rem)`    | 700            | 首页不常驻；同色系底上白字；蓝牙计时中仍用此级 |
| 观察倒计时         | `clamp(2.4rem, 12vw, 3.6rem)`    | 700            |                                                |
| 打乱 / 练习公式    | `clamp(1.05rem, 2.1vw, 1.35rem)` | 600            | 清晰无衬线；当前步高亮底                       |
| 结果弹层时间       | `clamp(2.4rem, 10vw, 3.4rem)`    | 700            |                                                |
| 正文 / 按钮        | `1rem`（约 16px）                | 按钮主操作 600 |                                                |
| 状态 / 旁注        | `0.85–0.95rem`                   | 400–500        |                                                |
| 统计微标           | `0.68–0.85rem`                   | 500            | Ao5 等                                         |

### 间距基准

| Token     | 值        | 用途                         |
| --------- | --------- | ---------------------------- |
| `space.1` | `4px`     | 紧凑内边距                   |
| `space.2` | `8px`     | 控件内间距、小间隙           |
| `space.3` | `10–12px` | 顶栏 padding、模块间常规 gap |
| `space.4` | `16–20px` | 区段间距、弹层内边距         |
| `space.5` | `24–32px` | 宽屏左右边距                 |

模块纵向节奏（首页）：顶栏 → 魔方区 → 打乱区 → 统计，区间以 `space.3`–`space.4` 分隔，不随意压缩到 `< 8px`。

## 5. 布局结构

窄屏单列；宽屏同一结构加宽边距与字号，不拆第二套布局。**不提供平面图**；首页以 3D 为唯一魔方预览。

### 首页（打乱计时）

自上而下（**非计时中**）：

1. **顶部栏**
   - 左：「练习」入口。
   - 中：已连接时「对齐朝向」**居中**显示；未连接时该位为空。
   - 右：蓝牙「连接 / 断开」；其旁为状态文案。
2. **3D 魔方**（主视觉）
   - 默认展示 **白上绿前还原态**（非蓝牙；蓝牙未跟转前同此朝向语义）。
   - 蓝牙引导阶段叠 3D 环绕箭头（约束见下）。
3. **打乱公式**：公式条 + 重新打乱。
   - **蓝牙**：步骤高亮 / 旁注；观察阶段整区换成倒计时面板。
   - **非蓝牙**：公式下方加 **播放控制条**（交互与视觉参考练习页：播放 / 暂停 / 步进等），用于按公式逐步打乱；魔方从白上绿前还原态起跟播。
4. **本机统计摘要**（非计时中常驻）：次数 / 最好 / Ao5 / Ao12 / Ao100 / AVG。
5. **计时器**：首页**不常驻**；仅进入计时画面后出现。

**不计时中不显示**大号 `0.000` 计时器。

#### 计时中布局（按模式）

- **非蓝牙**：只保留计时器大数字；隐藏顶栏、打乱区（含播放条）、魔方、统计摘要。
- **蓝牙**：隐藏顶栏、打乱区、统计摘要；**保留 3D 魔方跟随**；计时器为主视觉（更大数字、优先占位），魔方为辅。

#### 打乱引导箭头（蓝牙）

- 形态：贴在当前层上的 **3D 环绕箭头**（环带 + 指向），非平面贴图。
- 尺寸：可见弧 / 环的特征尺寸 **不小于魔方边长的 1/3**。
- 颜色：`color.highlight`（`#FFD500`）；转错修正可用危险浅系，但仍保持足够对比。
- 朝向：随魔方 / 陀螺仪朝向旋转，始终表示相对实体的转动方向。

#### 首页交互

- **非蓝牙开表**：仅点击**空白区域**或长按进入准备（计时数字出现并按危险色闪烁等反馈）；松手进入计时画面并开始计时。点击播放控制条、重新打乱、练习入口、蓝牙连接等**交互元素不触发准备**（事件需 `stopPropagation` / 命中检测排除控件）。空格行为与触控对齐（准备 → 开表），具体与状态机实现一致。
- **非蓝牙未完成打乱**：允许在打乱未完成（播放条未播完）时进入计时；从**当前魔方状态**开表，**不强制**打乱完成。
- **蓝牙**：保持现有流程——逐步打乱（引导）→ 观察倒计时（可跳过）→ 待转 → 实体首转开表 → 还原自动停。
- **还原后（停表确认关闭、进入下一轮）**：**只更新打乱公式**（刷新文案 / 引导进度）；**不修改当前 3D 魔方状态**（不把新打乱目标写回魔方；非蓝牙需用户再用播放条逐步打乱，蓝牙继续跟实体）。

### 练习页

自上而下：

1. **公式选择**：顶栏返回 + 当前公式触发器 → 弹层（分组 / 列表 / 缩略图）。
2. **蓝牙「一键打乱到状态」（预留）**：放在 **公式选择下方，或控制条上方**（与 3D 相邻的主操作带）；未实现前不占位强提示，实现时用主操作按钮，不挤进顶栏。
3. **3D 魔方**：练习朝向（黄上）；可简化贴图（F2L）。
4. **控制条**：公式步骤高亮、播放 / 暂停 / 步进、算法切换、相关开关。

本版不展开「一键打乱」交互细节；位置以上述两档为准，二选一时优先「公式选择下方」。

### 成绩展示（预留）

首页只放 **本机统计摘要**（次数 / 最好 / Ao5 / Ao12 / Ao100 / AVG）。**分段统计（Cross / F2L×4 / OLL / PLL）与图表不在首页堆叠**，统一放在后续「成绩」入口的 **成绩详情** 中展示：

- 列表项：总时间、日期；蓝牙成绩可带分段摘要一行（可选）。
- 详情：总览（步数、TPS、转体、停顿率）+ 分段表 + 趋势图（见 `prd.md`）。

专项视觉在成绩模块落地时补图，本文只锁定「首页不堆、详情承载」。

## 6. 蓝牙 / 非蓝牙差异

### 共用

- 整页色系、字号、间距、顶栏「练习」入口。
- 打乱公式展示区、唯一 3D 预览（无平面图）、计时中计时器外观、正常停表「保留 / 丢弃」弹层。
- 打乱朝向语义（白上绿前）与练习朝向（黄上）规则。
- 下一轮只刷新打乱公式、不改写魔方状态。

### 因模式不同

| 元素         | 非蓝牙                               | 蓝牙已连接                                       |
| ------------ | ------------------------------------ | ------------------------------------------------ |
| 开表         | 点击或长按准备 → 松手进入计时画面    | 引导完成 → 观察 → 待转 → **实体首转**开表        |
| 停表         | 再次点击 / 空格                      | 检测到还原自动停                                 |
| 计时中布局   | 仅计时器                             | 计时器（主）+ 3D 跟随（辅）                      |
| 打乱区       | 公式 + 刷新 + **播放控制条**逐步打乱 | 逐步高亮、转错修正、观察倒计时、「转动开始计时」 |
| 3D（非计时） | 默认白上绿前还原态，随播放条变化     | 跟随实体；引导环绕箭头                           |
| 顶栏         | 「连接」在右                         | 「对齐朝向」居中；「断开」+ 状态在右             |
| 触控开表     | 点击 / 长按准备                      | 禁用按住开表，避免与跟转冲突                     |
| 成绩内容     | 摘要在首页；分段在详情（待做）       | 同左；分段在成绩详情（待做）                     |

未连接时整页走非蓝牙流程，不混用蓝牙引导 UI。

## 7. 空状态与异常

| 场景               | 位置                         | 文案（约定）                                                                                                     |
| ------------------ | ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 未连接蓝牙         | 顶栏右侧主按钮               | 按钮：「连接」；无强制空态页                                                                                     |
| 连接中             | 顶栏按钮 + 状态              | 按钮禁用；状态可空或沿用加载态                                                                                   |
| 连接失败           | 顶栏状态（警告色）           | 「未选择魔方，或附近没有魔域设备」/「当前页面无法使用蓝牙…」/「蓝牙连接失败，请靠近魔方后重试」/「蓝牙连接失败」 |
| 已连接同步中       | 顶栏状态（警告色）           | `{设备名} · 同步中…`                                                                                             |
| 已连接可用         | 顶栏状态（成功色）           | `{设备名} · 已同步 · 朝向跟随`                                                                                   |
| 已对齐朝向         | 顶栏状态                     | `{设备名} · 已对齐朝向`                                                                                          |
| 断连（非计时中）   | 顶栏状态（警告色）           | 「魔方已断开」；UI 回到非蓝牙                                                                                    |
| 断连（蓝牙计时中） | 居中弹层                     | 「魔方已断开，本次成绩是否保留」；主按钮「保留」、次按钮「丢弃」；关闭后回非蓝牙首屏                             |
| 打乱转错           | 打乱公式下方旁注（危险浅字） | 「转错了，请转{修正步}」                                                                                         |
| 引导下一步         | 公式下方旁注                 | 「下一步{步}」+ 进度 `已完成/总数`；双步一半时加「（再转半步）」                                                 |
| 观察中             | 原打乱区                     | 标题「观察」+ 秒数 +「跳过观察」                                                                                 |
| 待转开表           | 公式下方旁注                 | 「转动开始计时」                                                                                                 |
| 计时中（非蓝牙）   | 全屏仅计时器                 | 无额外文案；再次操作停表                                                                                         |
| 计时中（蓝牙）     | 计时器 + 3D                  | 无额外文案；等还原自动停                                                                                         |
| 停表确认           | 居中弹层                     | 展示本次时长；主按钮「保留」、次按钮「丢弃」                                                                     |
| 无打乱公式         | 打乱区                       | 「点击右侧图标重新打乱」                                                                                         |
| 练习未选公式       | 练习控制区                   | 简短提示选择公式（沿用现有空态样式）                                                                             |
