# 产品设计（轻量）

对齐 `docs/prd.md` 的设计约束与已完成能力。本文锁定 UI/UE 统一时的色值、组件层级与文案；后续改布局以本文为准。窄屏优先，一套布局适配宽屏。

色值取自当前 Web 实现中已稳定使用的主色系，统一时优先收敛到下列 token，避免再散落新色。

## 1. 配色

| Token                                 | 色值                     | 用途                                                  |
| ------------------------------------- | ------------------------ | ----------------------------------------------------- |
| 主色 `color.primary`                  | `#4A7EB5`                | 计时区背景、结果确认底、主操作同色系强调              |
| 主色深 `color.primary-deep`           | `#2A5078`                | 主操作按钮上的深色字（浅底按钮）                      |
| 页面底 `color.surface`                | `#4A7EB5`                | 打乱计时 / 练习主舞台（计时中与首页一致）             |
| 深色块 `color.surface-dark`           | `#1C1F27`                | 打乱条、次按钮实心底、弹层深底                        |
| 浅色块 `color.surface-light`          | `#F3F0E8`                | 顶栏「练习」等浅底控件                                |
| 文字主（浅底上）`color.text-on-light` | `#12141A`                | 浅色按钮字、高亮步骤字                                |
| 文字主（深底上）`color.text`          | `#F7FBFF`                | 正文、公式、计时数字默认                              |
| 文字次 `color.text-muted`             | `#B7B1A4`                | 顶栏次要信息                                          |
| 文字弱 `color.text-dim`               | `#8D887D`                | 提示、禁用倾向说明、空状态                            |
| 高亮 `color.highlight`                | `#FFD500`                | 当前公式步、准备态强调、复选强调                      |
| 危险 `color.danger`                   | `#FF5A52`                | 需强警示、丢弃等                                      |
| 倒计时准备 `color.ready`              | `#B8F5C4`                | 非蓝牙长按倒计时亮相；暗相 `#6FD68A`，约 `1.15s` 一轮 |
| 危险浅字 `color.danger-soft`          | `#FFE0E0`                | 打乱转错提示                                          |
| 成功 `color.success`                  | `#D7FFE8`                | 蓝牙已连接状态                                        |
| 警告 `color.warning`                  | `#F0C9A0`                | 蓝牙过程提示（同步中、对齐等）                        |
| 边框 `color.border`                   | `rgb(247 251 255 / 42%)` | 次操作描边、卡片线                                    |
| 禁用                                  | 原色 + `opacity: 0.65`   | 连接中、不可点；光标 `wait` / `not-allowed`           |

魔方色块（3D / 练习缩略图）保持竞赛色：白 `#FFFFFF`、黄 `#F4F400`、绿 `#44EE00`、蓝 `#2266FF`、红 `#FF0000`、橙 `#FF8000`。不与 UI token 混用。

## 2. 图标

- **风格**：线性，描边约 1.5–2px，圆角端点；不使用彩色插画图标。
- **尺寸**：触控图标 `20×20`；与 `40px` 高圆角按钮居中。列表缩略图（OLL/PLL/F2L）单独尺寸，不与导航图标混用。
- **与文字**：
  - 主入口可只留图标（如首页「练习」）。
  - 主操作若空间紧可用「图标 + 短文案」；蓝牙连接 / 断开用顶栏图标（已连接为绿色，再点确认断开）。
  - 次操作默认文字（「跳过观察」、打乱/练习播放控件）；顶栏「对齐朝向」为图标按钮；窄屏可缩字，不改成纯图标除非已约定。
- **触控**：图标按钮最小点击区 `40×40`。

## 3. 交互

### 按钮层级

| 层级     | 视觉                                             | 典型操作                                       |
| -------- | ------------------------------------------------ | ---------------------------------------------- |
| 主操作   | 实心浅底 `#F7FBFF` + 深字，或深底实心 + 粗体白字 | 连接蓝牙、重新打乱、结果「保留」、练习播放主控 |
| 次操作   | 透明 / 深底 + 描边，或描边胶囊                   | 对齐朝向、跳过观察、打乱播放控制、算法切换     |
| 危险操作 | 描边浅字或与主操作对位的弱样式；文案明确         | 断开蓝牙、结果「丢弃」                         |

同一弹层内：「保留」为主，「丢弃」为次/危险弱样式，避免双主按钮。

### 反馈

- **点击**：按钮按下有背景或边框变亮；操作后 `blur`，避免挡住空格计时。
- **加载**：蓝牙连接中按钮 `disabled` + 状态文案（见第 7 节）。
- **成功 / 失败**：顶栏状态条或公式区旁注；失败用完整短句，不吞错。
- **计时准备（非蓝牙）**：打乱完成后**长按**进入计时画面（只留大号计时器），数字复位为 `0.00`、变 `color.ready` 浅绿闪烁；**松手**开始计时。短按则直接开表（无倒计时）。

### 动画时长

| 场景             | 时长 / 规则                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 非蓝牙长按倒计时 | 按住满 `300ms` 进入浅绿准备态；松手开表                                                                                                                             |
| 蓝牙跟转动画     | 单步约 `60–220ms`；协议间隔 `< 90ms` 或积压时瞬切                                                                                                                   |
| 蓝牙引导跟手     | 外层面转（含 R2）：转动包动画 + `applyGuidedMove`（半步不误判）。宽层 / 中层：转动包动画 + facelets 对表，动画中不硬切，到位后再钉中心。转体：陀螺仪跟手 + 烘焙贴纸 |
| 非蓝牙打乱播放   | 单步 `800ms`（含动画），便于对照实体跟拧；可暂停 / 单步                                                                                                             |
| 练习步骤播放     | 单步 `500ms`；用户可暂停 / 单步                                                                                                                                     |
| 观察倒计时       | 默认 `15s`，可跳过                                                                                                                                                  |
| 页面切换         | 不做大段过渡动画；以布局显隐为主                                                                                                                                    |

## 4. 字体与间距

### 字号与字重

| 角色               | 字号（窄屏 → 宽屏）                                   | 字重           | 备注                                                                      |
| ------------------ | ----------------------------------------------------- | -------------- | ------------------------------------------------------------------------- |
| 计时器（仅计时中） | 主段约 `clamp(5.2rem, 28vw, 9.5rem)`；厘秒约 `0.52em` | 700            | 两位厘秒；分/秒大、小数小；`≥10` 分 compact / 窄屏 tight，`≥100` 分 tight |
| 观察倒计时         | `clamp(2.4rem, 12vw, 3.6rem)`                         | 700            |                                                                           |
| 打乱 / 练习公式    | `clamp(1.05rem, 2.1vw, 1.35rem)`                      | 600            | 清晰无衬线；当前步高亮底                                                  |
| 结果弹层时间       | `clamp(2.4rem, 10vw, 3.4rem)`                         | 700            |                                                                           |
| 正文 / 按钮        | `1rem`（约 16px）                                     | 按钮主操作 600 |                                                                           |
| 状态 / 旁注        | `0.85–0.95rem`                                        | 400–500        |                                                                           |
| 统计微标           | `0.68–0.85rem`                                        | 500            | Ao5 等                                                                    |

### 间距基准

| Token     | 值        | 用途                         |
| --------- | --------- | ---------------------------- |
| `space.1` | `4px`     | 紧凑内边距                   |
| `space.2` | `8px`     | 控件内间距、小间隙           |
| `space.3` | `10–12px` | 顶栏 padding、模块间常规 gap |
| `space.4` | `16–20px` | 区段间距、弹层内边距         |
| `space.5` | `24–32px` | 宽屏左右边距                 |

模块纵向节奏（首页）：顶栏 → 魔方区 → 打乱区 → 统计，区间以 `space.3`–`space.4` 分隔，不随意压缩到 `< 8px`。打乱区内：公式与播放控制间距约半个控制钮高（≈ `20px`）；重新打乱与播放钮同径描边样式。

## 5. 布局结构

窄屏单列；宽屏同一结构加宽边距与字号，不拆第二套布局。**不提供平面图**；首页以 3D 为唯一魔方预览。

### 首页（打乱计时）

自上而下（**非计时中**）：

1. **顶部栏**
   - 左：「练习」入口。
   - 中：已连接时「对齐朝向」**图标居中**；未连接时该位为空。
   - 右：蓝牙「连接 / 断开」；其旁为状态文案。
2. **3D 魔方**（主视觉）
   - 默认展示 **白上绿前还原态**（非蓝牙；蓝牙未跟转前同此朝向语义）。
   - 蓝牙引导阶段叠空心描边框 + 四边同步短白箭头（约束见下）。
3. **上次成绩**：魔方下方大号数码；启动时从本机成绩恢复上一把，停表后更新。无成绩时同高占位（不可见），避免手机端首次出成绩时魔方上移。
4. **打乱公式**：公式条 + 重新打乱。
   - **蓝牙**：步骤高亮 / 旁注；观察阶段整区换成倒计时面板。
   - **非蓝牙**：公式下方加 **播放控制条**（交互与视觉参考练习页：播放 / 暂停 / 步进等），用于按公式逐步打乱；魔方从白上绿前还原态起跟播。
5. **本机统计摘要**（非计时中常驻）：次数 / 最好 / Ao5 / Ao12 / Ao100 / AVG。
6. **计时器**：准备态 / 计时中全屏大号；首页用「上次成绩」槽，不显示进行中的 `0.00`。

准备 / 计时全屏时隐藏「上次成绩」。手机端小数点用**菱形**（宽屏仍用圆点）。

#### 计时画面布局（准备态 + 计时中，按模式）

- **非蓝牙**：准备态与计时中均只保留计时器大数字；隐藏顶栏、打乱区（含播放条）、魔方、统计摘要。
- **蓝牙**：计时中隐藏顶栏、打乱区、统计摘要；**保留 3D 魔方跟随**；计时器为主视觉（更大数字、优先占位），魔方为辅。
- **放弃**：准备态 / 计时中右下角圆形图标按钮（×，`position: fixed` + 安全区，避免被 Grid 裁切）；点按后不记成绩、回首页并刷新打乱。

#### 打乱引导箭头（蓝牙）

- 形态：**空心亮色描边框**套住要转的那一层（无半透明填充，不洗贴纸色）+ **四边各一短白箭头** 同步沿各自边循环。
- 每边箭头约 `1.6s` 跑完该边并循环；背侧被挡时朝向镜头的边仍可见。不用贴面弯弧、不贴转动面中心。
- 描边框与箭头均开启深度测试：背侧被魔方挡住。
- 引导近白描边 + 白箭头；纠错红（`#FF5A52`）。双步略快；半步只显示相对两侧箭头。
- 朝向：挂在 Cube3D 上，随魔方 / 陀螺仪旋转。

#### 首页交互

- **非蓝牙开表**：
  - 打乱**未完成**：点击空白 / 空格 / **短按 3D** → **自动播放**打乱公式。
  - 打乱**已完成** + 短按 → **直接开表**（无倒计时）。
  - 打乱**已完成** + 长按（`300ms`）→ 进入倒计时（浅绿闪烁 `0.00`），**松手**开表。
  - **3D 魔方**：短按与空白区相同；按下后移动超过约 `12px` 则取消开表手势，交给旋转查看。
  - 计时中再按空格 / 点击停表。播放控制条、重新打乱、练习入口、蓝牙连接等**交互元素不触发**上述手势。
- **蓝牙**：逐步打乱（引导）→ 观察倒计时（可跳过；观察中拧动立刻开表；**倒计时归零直接开表**）→ 跳过则待转、实体首转开表 → 还原自动停 → **进入全屏成绩复盘页**。
- **还原后（停表回首页 / 下一轮）**：
  - **非蓝牙**：停表回到首页时，3D 魔方复位为**白上绿前复原态**，播放进度归零；关闭确认后**只更新打乱公式**（不把新打乱目标写回魔方，需再用播放条逐步打乱）。
  - **蓝牙**：进入复盘页即保存；用户返回（或滑动返回）只退出查看并**只刷新打乱公式**；**不改写** 3D（继续跟实体）。也可「再练一次」用相同打乱重开。

### 练习页

自上而下：

1. **公式选择**：顶栏返回 + 当前公式触发器 → 弹层（分组 / 列表 / 缩略图）。
2. **蓝牙「一键打乱到状态」（预留）**：放在 **公式选择下方，或控制条上方**（与 3D 相邻的主操作带）；未实现前不占位强提示，实现时用主操作按钮，不挤进顶栏。
3. **3D 魔方**：练习朝向（黄上）；可简化贴图（F2L）。
4. **控制条**：公式步骤高亮、播放 / 暂停 / 步进、算法切换、相关开关。

本版不展开「一键打乱」交互细节；位置以上述两档为准，二选一时优先「公式选择下方」。

### 成绩展示

首页只放 **本机统计摘要**（次数 / 最好 / Ao5 / Ao12 / Ao100 / AVG）。**分段统计与图表不在首页堆叠**，由「成绩」入口承载：

- **列表**：总时间、日期；蓝牙成绩可带分段摘要；支持查看复盘 / 再练 / 删除等操作。
- **复盘详情**：蓝牙还原后进入全屏复盘页（总览、分段公式、回放、再练一次）；亦可从列表进入。
- **图表**：汇总与趋势（基础版已落地）。

首页不堆分段与图表；细则见 `prd.md`。

## 6. 蓝牙 / 非蓝牙差异

### 共用

- 整页色系、字号、间距、顶栏「练习」入口。
- 打乱公式展示区、唯一 3D 预览（无平面图）、计时中计时器外观；非蓝牙停表「保留 / 丢弃」弹层；蓝牙还原进入全屏成绩复盘页（总览 + 分段 + 回放）。
- 打乱朝向语义（白上绿前）与练习朝向（黄上）规则。
- 下一轮刷新打乱公式；非蓝牙停表回首页时魔方复位复原态，蓝牙不改写魔方（跟实体）。
- 蓝牙品牌：系统选择窗按设备名自动匹配魔域 / Gan；断开后 3D 回到白上绿前复原预览。

### 因模式不同

| 元素         | 非蓝牙                                | 蓝牙已连接                                                       |
| ------------ | ------------------------------------- | ---------------------------------------------------------------- |
| 开表         | 点击或长按进入计时画面准备 → 松手开表 | 引导完成 → 观察（拧动 / 倒计时归零直接开表）/ 跳过则待转首转开表 |
| 停表         | 再次点击 / 空格                       | 仅白上绿前复原自动停；点击 / 空格不停表                          |
| 停表后       | 「保留 / 丢弃」确认后记成绩           | 进入全屏成绩复盘页即保存                                         |
| 计时画面     | 准备态 / 计时中均仅计时器             | 计时器（主）+ 3D 跟随（辅）                                      |
| 打乱区       | 公式 + 刷新 + **播放控制条**逐步打乱  | 逐步高亮、转错修正、观察倒计时、「转动开始计时」                 |
| 3D（非计时） | 默认白上绿前还原态，随播放条变化      | 跟随实体；引导层空心描边框 + 四边同步短白箭头                    |
| 顶栏         | 蓝牙图标在右                          | 「对齐朝向」图标居中；蓝牙图标变绿；再点确认断开                 |
| 触控开表     | 点击 / 长按准备                       | 禁用按住开表，避免与跟转冲突                                     |
| 成绩内容     | 摘要在首页；列表 / 图表在成绩页       | 同左；还原后进复盘全屏页，亦可从列表进入                         |

未连接时整页走非蓝牙流程，不混用蓝牙引导 UI。

## 7. 空状态与异常

| 场景               | 位置                          | 文案（约定）                                                                                                     |
| ------------------ | ----------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 未连接蓝牙         | 顶栏右侧图标按钮              | 蓝牙图标；无强制空态页；不常驻说明文字                                                                           |
| 浏览器不支持蓝牙   | Toast（短暂）                 | 「当前浏览器不支持蓝牙」；**不**在顶栏常驻；图标仍可点出 Toast（不改 `requestDevice` 原生窗）                    |
| 连接中             | 顶栏图标                      | 按钮禁用；首页**不**显示设备名                                                                                   |
| 连接失败           | 顶栏旁注（警告色）            | 「未选择魔方，或附近没有魔域设备」/「当前页面无法使用蓝牙…」/「蓝牙连接失败，请靠近魔方后重试」/「蓝牙连接失败」 |
| 已连接可用         | 顶栏图标（绿色）              | 图标变为绿色表示已连接；首页**不**显示设备名；再点图标弹出断开确认                                               |
| 断开确认           | 居中自定义弹层                | 文案「断开魔方连接？」；主危险「断开」、次「取消」；首次连接仍用原生 `requestDevice`                             |
| 已对齐朝向         | Toast（短暂）                 | 「已对齐朝向」；不在顶栏堆设备名                                                                                 |
| 断连（非计时中）   | 顶栏状态（警告色）            | 「魔方已断开」；UI 回到非蓝牙                                                                                    |
| 断连（蓝牙计时中） | 居中弹层                      | 「魔方已断开，本次成绩是否保留」；主按钮「保留」、次按钮「丢弃」；关闭后回非蓝牙首屏                             |
| 打乱转错           | 打乱公式下方旁注（危险浅字）  | 「转错了，请转{修正步}」                                                                                         |
| 引导下一步         | 公式下方旁注                  | 「下一步{步}」+ 进度 `已完成/总数`；双步一半时加「（再转半步）」                                                 |
| 观察中             | 原打乱区                      | 标题「观察」+ 秒数 +「跳过观察」；拧动立刻开表；倒计时归零直接进入计时并开表                                     |
| 待转开表           | 公式下方旁注                  | 「转动开始计时」（仅跳过观察后；倒计时归零不再经过此态）                                                         |
